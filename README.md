# Лабораторная работа №2 — Вариант 6 «Работники» + «Предложения без запятых»

Консольная программа на C++ из двух частей:

1. **Стандартные потоки.** Класс `Worker` (WORKER): ФИО, должность, год поступления на работу.
   Для него перегружены операции вставки `<<` и извлечения `>>`. Работники хранятся в контейнере
   `WorkerList` в алфавитном порядке; программа выводит фамилии работников, чей стаж больше
   введённого с клавиатуры значения, или сообщение, что таких нет.
2. **Файловые и строковые потоки.** Класс `TextDocument` читает текст из файла (`ifstream`),
   разбивает его на предложения (`istringstream`/`ostringstream`) и выводит только предложения
   без запятых.

В меню можно изменить любую запись, удалить любой объект и добавить новый на любую позицию —
и для работников, и для предложений текста.

## Структура проекта

```
lab2/
├── src/
│   ├── main.cpp            — точка входа: меню и диалог с пользователем
│   ├── core/               — абстрактный базовый класс Person (ФИО)
│   ├── entities/           — Worker (наследник Person), операторы << и >>
│   ├── container/          — WorkerList: список работников, файл сохранения
│   ├── text/               — TextDocument: текст из файла, разбор на предложения
│   ├── exceptions/         — AppException
│   ├── input/              — ввод чисел и строк с клавиатуры с проверкой
│   └── utils/              — функции для строк UTF-8 (алфавитное сравнение, выравнивание)
├── examples/
│   ├── workers_example.txt — готовый список из 6 работников (пункт 9)
│   └── text_example.txt    — текст для второй части (пункт 12)
├── build.bat / build.sh    — сборка через g++
├── CMakeLists.txt          — проект для Visual Studio / CLion
└── build/                  — сюда собирается workers.exe (не хранится в git)
```

В каждой папке `src/` есть свой README с описанием файлов.

## Сборка и запуск

Windows, g++ (MinGW/MSYS2):
```
build.bat
build\workers.exe
```

Visual Studio 2022: «Файл → Открыть → Папка», выбрать `lab2` — проект подхватится из `CMakeLists.txt`,
выбрать цель `workers.exe` и запустить.

Linux / macOS / Git Bash:
```
./build.sh
./build/workers
```

Текстовые файлы должны быть в кодировке UTF-8.
