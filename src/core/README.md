# core — базовый класс

`Person.h` Абстрактный класс `Person` («человек»): поле `fullName` (ФИО), чисто виртуальные `getRole` и `print`, виртуальный деструктор
`Person.cpp` Конструкторы/деструктор с выводом сообщений, `getFullName`/`setFullName`, `getSurname` (фамилия — первое слово ФИО), проверка ФИО `checkFullName`

Отдельно, потому что от этого класса зависит `Worker`, а сам он ничего не знает ни о работниках, ни о списке.
