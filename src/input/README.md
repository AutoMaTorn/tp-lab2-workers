# input — ввод с клавиатуры

Функции в пространстве имён `Input` (не класс, а набор функций):

`readString` читает целую строку (можно с пробелами)
`readInt(min, max)` повторяет запрос, пока не введено целое число из диапазона; строка разбирается строковым потоком

Если ввод закрыт (Ctrl+Z), бросают `AppException`, и программа корректно завершается.
