# utils — функции для строк

Пространство имён `TextUtils`:

`isBlank`, `trim` — пустая ли строка, обрезка пробелов
`length`, `padRight` — длина в символах (а не байтах UTF-8) и выравнивание столбцов таблицы
`compareAlpha` — сравнение по алфавиту без учёта регистра: русские буквы по порядку, «ё» сразу после «е»
`firstWord` — первое слово (фамилия из ФИО), через `istringstream`
`yearsWord` — «1 год», «3 года», «7 лет»
