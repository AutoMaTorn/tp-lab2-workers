# exceptions — исключения

`AppException` — наследник `std::exception`, хранит текст ошибки и возвращает его через `what()`.
Бросается при неверных значениях полей, неверном номере или позиции, ошибках открытия и чтения файлов.
Перехватывается в главном цикле `main.cpp` — пользователь видит текст ошибки, программа продолжает работу.
