# text — вторая часть задания (файловые и строковые потоки)

`TextDocument.h/.cpp` Класс `TextDocument`: имя файла и динамический массив предложений `std::string* sentences`

- `loadFromFile` — файл открывается `std::ifstream` и целиком переносится в `std::ostringstream` (`buffer << file.rdbuf()`);
- `splitIntoSentences` — текст читается посимвольно из `std::istringstream`; предложение заканчивается на `.`, `!`, `?` или `…`
  (вместе с идущими следом знаками и закрывающими кавычками), если после него пробел или конец текста;
- `normalize` — строковыми потоками убирает лишние пробелы и переводы строк внутри предложения;
- `printWithoutCommas` — **вывод предложений без запятых** (или сообщение, что таких нет);
- изменение, удаление, вставка предложения на любую позицию; сохранение в файл `std::ofstream`.
