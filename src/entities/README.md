# entities — работник

`Worker.h/.cpp` `Worker` (WORKER из задания) — наследник `Person`: должность `position`, год поступления `hireYear`

Что есть в классе:
- конструкторы без параметров, с параметрами, копирования и деструктор (все печатают сообщение);
- `get`/`set` для каждого поля, `set` проверяют значение и бросают `AppException`; `setAll` — все поля сразу;
- `getExperience()` — стаж (текущий год по часам компьютера минус год поступления);
- операторы `=`, `==`, `<` (сравнение по алфавиту, нужно для упорядочивания);
- **перегруженные операции вставки `<<` и извлечения `>>`**:
  `>>` читает три строки (ФИО, должность, год) из любого потока — с клавиатуры печатает подсказки,
  из файла читает молча; год разбирается строковым потоком `istringstream`;
- `save` — запись полей в файл в том формате, который понимает `>>`.
