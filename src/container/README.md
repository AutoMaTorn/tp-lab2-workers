# container — список работников

`WorkerList.h` Класс `WorkerList`: название организации и динамический массив `Worker** items` (`count` элементов, ёмкость `capacity`)
`WorkerList.cpp` Вставка на позицию (`insertAt`), вставка по алфавиту (`addSorted`, `+=`), удаление (`remove`), очистка, доступ `[]`, сортировка вставками (`sortByName`), поиск по стажу (`printExperiencedOver`), вывод таблицей, глубокое копирование, сохранение в файл и загрузка из файла

Список **владеет** работниками: удаляет их в `remove`, `clear` и деструкторе.
Загрузка из файла читает каждого работника тем же оператором `>>`, что и ввод с клавиатуры.
Формат файла — см. `examples/workers_example.txt`.
